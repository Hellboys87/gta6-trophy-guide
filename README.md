An offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide to each in our own words that cites its sources, a roadmap to the platinum, every missable flagged, a checklist whose progress is saved in the browser with export and import, filters by kind, and a spoiler setting that hides story trophies until they are earned. Static files only — it runs with the network off.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
